## About the Game
Ping Pong is an arcade paddle game built with Python and Pygame where two players—or one player against an AI opponent—rally a ball across an 800x500 arena. The goal is to score points by getting the ball past your opponent's paddle and be the first to reach 7 points.

## How to Play
- **1** (on menu): Start **Two Players** mode.
- **2** (on menu): Start **Play vs AI** mode.
- **W / S**: Move the left paddle up and down.
- **Up / Down Arrow Keys**: Move the right paddle up and down (in Two Players mode).
- **P** or **Pause** (or **Pause / Resume** button at the bottom): Pause or resume the match.
- **SPACE** (when game is over): Restart the match.
- **ESC**: Return to the main menu.

## Features
- **Two Game Modes:** Play locally against another human (2-player) or challenge an AI opponent.
- **First-to-7 Scoring:** Tracks scores for both sides and declares a winner once a player reaches 7 points.
- **Angle-Based & Speed-Scaling Bounces:** Hitting the ball off-center on a paddle adjusts its vertical rebound angle, and each paddle hit gradually speeds up the ball up to a cap.
- **Pause & Restart Controls:** Pause anytime with `P` or the on-screen button, restart after a match with `SPACE`, or return to the menu with `ESC`.
- **Custom Visual Theme:** Uses a deep navy background with complementary blue and orange paddles/scores, a dashed center line, and a soft glow behind the ball.
